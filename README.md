# 🌸 File-Encryption-App-Project 🌸

Welcome to the **File Encryption App**, a beautifully simple desktop application designed to keep your private files secure! With a user-friendly GUI, you can easily lock and unlock your files with a secure password. 

![App Interface](./assets/gui.png)

## ✨ Features
- **Secure Encryption**: Uses robust Fernet (AES-128) encryption. 
- **On-Demand Passwords**: Prompts for a password only exactly when you need to encrypt or decrypt, making it simple and secure. 
- **Consistent Keys**: Derives a 32-byte key automatically from your password using SHA-256 so you'll never lose access to your encrypted files! 
- **Batch Processing**: Select and encrypt/decrypt multiple files at once. 

## 🚀 How to Use
1. **Run the App**: Execute `python "PYTHON PROJECT FINAL.py"` in your terminal.
2. **Encrypt**: Click the 'Encrypt' button, type a secure password, and select the files you wish to lock.
3. **Decrypt**: Click the 'Decrypt' button, type the same secure password, and select your locked files to restore them!

Keep your files safe and secure! 🔒💖
